# Recursos provisionales

## Fotografía

Archivo: `public/images/editorial.png`. Creado para este proyecto con la herramienta integrada ImageGen (no CLI). Persona ficticia. Se reutiliza mediante encuadres CSS para mostrar posiciones de las fotos futuras.

Prompt final:

> Use case: photorealistic-natural. Asset type: full-bleed editorial placeholder photo for an elegant quinceañera save-the-date web experience. One single vertical photograph, no collage, no text. A fictional teenage celebrant in a modest full-length muted plum formal dress with soft blush tulle, standing on a sophisticated terrace at blue hour, looking back gently toward camera. Mid/full length portrait, naturally beautiful candid editorial mood, no crown. City skyline at twilight with warm distant bokeh, several real candles on stone balustrade, minimal pale roses at bottom corner. Deep navy near-black shadows, muted plum sky, warm ivory candlelight and subtle rose gold. Subject centered with generous dark sky above and shadowed foreground below for typography. Photographic luxury fashion campaign, soft cinematic grain, realistic skin and hands, tasteful and age appropriate. Vertical 1024x1536. Avoid glitter, bright pink, typography, logos, watermark.

## Audio

Archivo: `public/audio/twilight.wav`. Música ambiental sintetizada para este proyecto: cuatro acordes, arpegio suave y entrada/salida gradual, 48 segundos, mono PCM de 22.05 kHz. No contiene una grabación comercial. Es una guía de ambiente reemplazable, no la canción definitiva.
